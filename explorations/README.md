# Eksplorasi arah gaya (arsip)

Tiga arah gaya yang diuji sebelum memilih **Sudut Enam**:
`Jejak` (goresan menerus), `Sudut Enam` (kisi heksagon), `Tulis Tangan`
(goresan spidol lebar variabel).

Varian Sudut Enam dari file-file ini sudah dipindahkan dan dikembangkan di
`src/icons/hexcut/`. File di sini disimpan sebagai catatan keputusan; jangan
diimpor dari kode app.

Halaman perbandingan yang menyertainya ada di `preview/`:
`ceklis-arah-gaya.html`, `tas-dompet-arah-gaya.html`, `empat-ikon-tiga-gaya.html`.
